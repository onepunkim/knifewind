# 칼바람 나락 (KNIFEWIND 1PUN)

치지직 방송 시청자 참여(시참) 칼바람 나락 경기만 기록하는 전적·랭킹 사이트입니다.

- 기술: Next.js 16 + TypeScript + Supabase(PostgreSQL), 배포는 Vercel
- 로그인: 치지직 OAuth → Riot ID 입력 → 관리자 승인 후 정식 회원
- 경기 기록: 시참 세션 → Riot API로 경기 후보 조회 → **관리자가 승인한 경기만** 전적과 랭킹에 반영
- 페이지: 홈, 경기 기록, 명예의 전당, 마이페이지, 회원 전적, 관리자(회원·세션·경기·시즌·공지·통계)

## 먼저 알아 둘 것 (확인된 것과 확인하지 못한 것)

만든 쪽에서 직접 확인한 것: 타입 검사와 빌드 통과, 가짜 데이터베이스를 붙여 모든 화면이 열리는 것, 로그인 시작·로그아웃·관리자 폼 동작, 순위·KDA 계산 시험.

**실제 서비스에 연결해서는 확인하지 못한 것** (처음 연결할 때 이 부분을 가장 먼저 시험해 보세요):

1. **치지직 로그인**: 공식 문서에 적힌 방식으로 만들었지만 실제 치지직 서버와는 시험하지 못했습니다. 로그인이 안 되면 Vercel의 Logs 화면에 `[chzzk]`로 시작하는 오류가 남으니 그 내용을 알려 주세요.
2. **사용자 설정 내전**: Riot 경기 목록에 사용자 설정 게임이 나오는지 확인하지 못했습니다. 후보에 안 나오면 관리자 > 경기 기록 > '경기 직접 등록'으로 입력하면 됩니다.
3. **증바람**: 증바람의 큐 ID를 2400으로 가정했지만 Riot 공식 문서에서 확인하지 못했습니다. 증바람 후보가 '기타'로 나오면 `src/lib/riot-parse.ts`의 `guessMode` 숫자를 고치면 되고, 승인할 때 모드를 직접 고를 수도 있습니다. 게임 클라이언트(LCU)로 가져오는 방식은 웹사이트에서 쓸 수 없어서 넣지 않았습니다.
4. **Riot API 키**: 개발용 키는 24시간마다 만료됩니다. 계속 운영하려면 Riot 개발자 포털에서 제품 등록과 승인을 받아 상시 키를 받아야 합니다. 키(앱)를 바꾸면 회원의 PUUID 값이 달라질 수 있어서 관리자 > 회원 화면에 'PUUID 다시 조회' 버튼을 넣어 두었습니다.

## 설치 순서 (한 번에 하나씩)

### 1단계. 계정 만들기
GitHub, Supabase, Vercel 계정을 만듭니다. 모두 무료로 시작할 수 있습니다.

### 2단계. 코드를 GitHub에 올리기
GitHub에서 새 저장소(Repository)를 만들고, 이 폴더의 파일을 올립니다. (`node_modules`, `.next`, `.env.local` 폴더/파일은 올리지 않습니다. 압축 파일에는 들어 있지 않습니다.)

### 3단계. Supabase 데이터베이스 만들기
1. Supabase에서 새 프로젝트를 만듭니다. 지역은 Northeast Asia (Seoul)을 고르세요.
2. 왼쪽 메뉴 SQL Editor를 열고 `supabase/schema.sql` 파일 내용 전체를 붙여 넣은 뒤 Run을 누릅니다.
3. Project Settings > API에서 **Project URL**과 **service_role 키**(새 화면에서는 Secret key)를 복사해 둡니다. 이 키는 비밀번호와 같으니 절대 공개하지 마세요.

### 4단계. Riot API 키 받기
Riot 개발자 포털(developer.riotgames.com)에 로그인해 Development API Key를 복사합니다. 시험용은 24시간마다 다시 받아야 합니다. 정식 운영 전에 제품 등록(Register Product)을 신청하세요.

### 5단계. Vercel에 올리기
1. Vercel에서 Add New > Project로 2단계의 저장소를 가져옵니다.
2. Environment Variables에 `.env.example`에 적힌 이름 그대로 값을 넣습니다. (`CHZZK_*`는 아직 비워 두어도 됩니다.)
   - `SESSION_SECRET`: 32자 이상 아무 글자나 길게 만들어 넣습니다.
   - `SITE_URL`: 일단 `https://임시주소.vercel.app` 형태의 배포 주소를 넣습니다. 배포 후 실제 주소로 고칩니다.
   - `ADMIN_CHZZK_CHANNEL_IDS`: 방장 본인의 치지직 채널 ID입니다. 방송 채널 주소 `chzzk.naver.com/` 뒤의 긴 글자입니다.
3. Deploy를 누릅니다. 끝나면 나오는 주소로 접속해 홈 화면이 뜨는지 봅니다.

### 6단계. 치지직 로그인 연결
1. 치지직 개발자 센터에서 애플리케이션을 등록합니다. (안내: https://chzzk.gitbook.io/chzzk)
2. 로그인 Redirect URI에 `https://배포주소/api/auth/chzzk/callback`을 정확히 입력하고, 사용자 정보 조회 권한을 선택합니다.
3. 발급된 Client ID와 Client Secret을 Vercel의 `CHZZK_CLIENT_ID`, `CHZZK_CLIENT_SECRET`에 넣고 Redeploy 합니다.
4. 사이트에서 치지직으로 로그인해 보세요. 방장 채널 ID로 로그인하면 자동으로 관리자가 됩니다.

### 7단계. 첫 운영
1. 관리자 > 시즌에서 시즌 이름을 고칩니다.
2. 시청자가 가입하면 관리자 > 회원 > '승인 대기'에서 Riot ID를 확인하고 승인합니다.
3. 방송을 시작하면 관리자 > 시참 세션 > '세션 시작'.
4. 경기가 몇 판 끝나면 세션 화면에서 '경기 후보 조회'를 누르고, 실제 시참 경기만 '시참 경기로 승인'합니다.
5. 방송이 끝나면 '세션 종료' 후 한 번 더 '경기 후보 조회'로 빠진 판이 없는지 봅니다.

## 알아 둘 동작
- 전적과 랭킹은 승인된 경기에서 자동 계산됩니다. 승인 취소하거나 수정하면 바로 바뀝니다.
- 가입하지 않은 참가자의 Riot ID는 공개 화면에 나오지 않고 '비회원'으로 표시됩니다. (관리자 화면에서는 보임)
- 승률·KDA 순위는 5판 이상 참여한 회원만 올라갑니다. (`src/app/hall-of-fame/page.tsx`의 `MIN_GAMES`)
- KDA는 (킬+어시스트)÷데스이고, 데스가 0이면 1로 계산합니다.
- 후보 조회는 한 번에 최대 약 40초 일하고, 남은 것은 다시 눌러 이어서 처리합니다. (Riot 요청 제한 때문)
